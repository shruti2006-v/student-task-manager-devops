# Student Task Manager — DevOps Mini Project

A small Flask task manager used to demonstrate Git/GitHub version control, GitHub Actions CI, automated tests, Docker containerization, and local deployment.

## Features
- Add tasks
- Mark tasks complete / undo completion
- Delete tasks
- Health endpoint at `/health`
- Automated tests using pytest
- GitHub Actions workflow runs tests and builds a Docker image

## Run locally (Python)
```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux:
# source .venv/bin/activate
pip install -r requirements-dev.txt
python app.py
```
Open http://127.0.0.1:5000

## Run tests
```bash
pytest -v
```

## Run with Docker
```bash
docker build -t student-task-manager .
docker run --rm -p 5000:5000 student-task-manager
```
Open http://localhost:5000. Check health at http://localhost:5000/health.

## GitHub Actions
Push this repository to GitHub. The workflow in `.github/workflows/ci.yml` runs on pushes and pull requests to `main` or `master`, executes the test suite, then builds the Docker image. See the Actions tab for run status.

## Important limitations
- Tasks are stored in memory, so they reset when the application restarts.
- The workflow builds the image but does not publish it to a registry or deploy to an external cloud host. Local Docker execution is the deployment demonstration. Add registry/hosting deployment only if required by the instructor.
- GitHub Actions and Docker results must be generated by running the workflow/build; do not report them as successful until verified.
